A personal utility, not a public service

This app is operated for its owner's personal use. It runs as a scheduled script on the owner's server; this website provides information and policies, not a sign-in or file-upload service.

What the importer does

  • Reads Drive file metadata and tracks newly visible files using an import checkpoint.
  • Exports Google Docs as Markdown and converts other supported document formats locally.
  • Saves the resulting files to the owner's second-brain inbox.
Read-only Google Drive access. The importer requests permission to view and download accessible Drive files. It does not upload, edit, delete, or change sharing permissions on Drive.

Understand the scope

The current importer is not limited to one selected folder. Its authorization can cover files accessible to the authorized account. It is a one-way import of newly visible files, not a two-way sync or a guarantee that later edits and deletions will be reflected locally.

Read the privacy policy for details about credentials, local storage, and second-brain synchronization.
